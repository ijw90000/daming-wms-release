当前版本（v10.41）全部功能

一、隐私与安全
  • 隐私锁：数字密码 / 九宫格手势 / 本机人脸指纹，三选一或组合使用。
  • 打开 App、从后台切回均需解锁验证；解锁页按返回不会绕过，只会退回桌面。
  • 自动重新锁定时间可配置（立即 / 1 分钟 / 5 分钟）；修改或关闭隐私锁需先验证身份。
二、物资与仓库档案
  • 档案页顶部并列「📦 物资档案」「🏭 仓库档案」切换按钮，点击切换显示对应页面。
  • 物资新增 / 编辑：编码、名称、规格、单位、分类、单价、默认仓库、位置、备注、预警值（默认 1）。
  • 删除物资时其台账记录一并删除；仓库与位置全 App 统一按「字母数字自然升序」排列（含中文数字按数值排序）。
  • 物资档案列表显示实时总库存（带单位）、位置，库存 ≤ 预警值的物资红底高亮。
三、出入库点验
  • 物资「点击搜索选择」（名称 / 编码 / 规格关键字），弹窗显示各仓库存分布；出库模式不显示零库存物资。
  • 选定物资后自动回填「档案位置」；仓库下拉按名称自然升序排列并标注实时库存，自动默认选中第一个有库存的仓位。
  • 出库事由默认：分类含「生活」→「生活自用」，其余→「工作自用」（仅空时回填，可改）；入库默认「入库记录」，切出库自动清理。
  • 出库领用人为 王刚 / 王俊健 / 何亚博 / 程国栋 / 潘家乐 时，领用单位自动默认 87km；领用人支持历史记录自动补全。
  • 经手人默认值；操作时间默认可改（v8.05 起受权限控制：普通用户只读，需管理员在「用户管理」里为该账号勾选「允许修改台账记录上的时间」；管理员本人始终可改）；「备注」位于事由下方；出库实时校验库存，不足直接拦截并提示差额（带单位）。
四、物资调拨
  • 支持物资关键字搜索（不显示零库存物资）；选定物资后显示「档案位置」，调出仓库自动选中有库存的仓。
  • 新增「调入仓库位置」填写项；调拨完成后物资档案的仓库与位置自动跟随变更为调入仓库与调入位置。
  • 调出前校验库存，不足拦截；调出 / 调入仓库不可相同。
五、废旧物资处理
  • 物资「点击搜索选择」（不显示零库存物资），选定后显示「档案位置」；仓库下拉按有库存优先并标注库存数。
  • 支持处置原因、备注、操作时间；处理前校验库存。
六、仓库工具借还（新）
  • 业务页新增「🔧 工具借还」入口，内分「借出登记 / 未归还 / 已归还」三个标签页。
  • 借出登记：选择工具物资（零库存也能选，因为工具不占库存）、填写借出数量、借用人、借用单位、经手人、借用事由与时间；借用人为 王刚 / 王俊健 / 何亚博 / 程国栋 / 潘家乐 时自动默认 87km。
  • 归还销账：支持一次借出分多次归还，归还时自动校验「归还数量不得超过未归还数量」；同一次借出与它的所有归还共用同一个借还单号。
  • 不占用库存：借出、归还全程只写台账明细，物资库存数量不变，也不会被计入出入库统计。
  • 未归还列表按借出时间倒序，直接显示「已借出 / 已归还 / 未归还」三列数量，点「归还」即可销账，点「明细」查看该单完整历史；已归还列表只列已结清的借还单。
七、查询与统计
  • 物资查询：一级仓库筛选（选定后只显示该仓有库存的物资）+ 二级位置筛选；不显示零库存物资；点击物资查看历史领取记录。
  • 库存查询：一级仓库 + 二级位置组合筛选，不显示零库存记录，结果按 仓库 → 位置 → 名称 自然升序。
  • 库存预警：实时库存 ≤ 预警值（默认 1）自动列出，红底高亮，显示缺口数量。
  • 领用统计：按领用人聚合，累计数量倒序排名，可查看明细，支持关键字筛选。
八、盘点
  • 按仓库分组盘点，系统库存与实际数量对比显示差异（带单位），支持盘点历史查询。
  • 盘点人默认按登录账号带入（管理员账号默认「徐维明」），可手动改成他人，清空后自动回填。
九、台账与报表
  • 台账筛选标签：全部 / 入库 / 出库 / 调拨 / 废旧 / 盘点 / 工具借还；工具标签下同时包含借出与归还两类记录。
  • 台账搜索支持中文关键字（如「工具」「借还」「借出」「归还」）与借还单号（如 #3）。
  • 每行显示「类型 · 仓库 · 位置 · 经手人」；工具借还行显示「类型 · 仓库 · 借用人 X · 经手人 Y」，数量下方标注「不占用库存（当前总库存 X）」。
  • 所有类型记录都在数量下方显示该物资总库存，出库行显示剩余库存；支持修改业务发生时间。
  • 台账按时间倒序，最新记录在最上面；同一时间戳的多条记录按录入先后排列，最后录入的在最上面。
  • 台账导出 CSV / Excel：含「位置」（仓库旁）与「当前库存」（数量旁）列；工具借出 / 归还行的「仓库」列导出真实仓库名（= 物资默认仓库，旧记录缺失时自动回落）；按时间倒序；已删除物资档案的记录不导出。
  • 一键生成日报 / 周报 / 月报（按日期聚合台账），导出 Excel。
  • 物资档案 / 实时库存与预警可导出 Excel，表头与 App 内口径一致（「位置」列、预警值）。
  • 导出台账时可选列：勾选需要导出的列（类型 / 物资 / 规格 / 单位 / 仓库 / 位置 / 数量 / 当前库存 / 经手人 / 领用人 / 领用单位 / 时间 / 备注），可「保存为默认」下次沿用。
  • 导出可视化报表：单文件 HTML，含 12 个月出入库趋势、分类与仓库库存占比、呆滞物资 Top、报废率 Top 及汇总明细表，可打印 / 另存 PDF。
十、数据安全与更新
  • 首页「数据安全」卡片新增「数据管理」入口：点击进入导出 / 导入 / 备份还原页，可直接「导出数据(JSON，可导入iOS)」与「备份数据库(.db，仅本机)」。
  • 数据库备份 / 还原，备份文件保存在 内部存储/Download/大明智仓管家/（公共目录，文件管理器可见）。
  • 邮件自动备份分类定时：每日 数据库+物资档案+台账日报；每周一 台账周报；每月 1 号 台账月报，到期合并一封邮件发送到指定邮箱。
  • 联网自动检测新版本：打开 App 自动检查，有新版弹窗提醒，支持自动下载安装 / 浏览器下载；多地址自动尝试并记住可用地址；首页版本号长按可手动检查。
  • 旧版备份还原后自动补齐数据库结构，不闪退。
十一、库存健康
  • 库存分析：按 30 / 60 / 90 / 180 / 365 天筛出呆滞物资（最后动销日、积压天数、占用金额），并统计各物资报废率。
十二、数据治理与追溯
  • 回收站：删除物资 / 台账 / 盘点单前先存快照，可还原（台账与盘点单会重新校准库存）或彻底删除，也可一键清空。
  • 操作日志：登录 / 退出 / 各类业务登记 / 增删改 / 数据操作全记录（操作人 + 时间），支持筛选、搜索与导出 CSV。
  • 物料照片：拍照 / 选图自动压缩后本机保存，列表与编辑页可见，可随时删除。
  • 扫码定位：安卓摄像头扫码 + 扫码枪，扫编码即定位物资。

十五、界面自适应与滚动（v8.06）
  • 自适应滚动条：需要滚动才有滚动条——内容装得下时完全不显示，装不下时自动出现；高度全部按屏幕实际可用高度实时计算（顶栏 + 底部导航 + 安全区 + 内边距），手机横竖屏切换、地址栏伸缩、电脑窗口拖拽拉伸都会立即重算。
  • 滚动条常显：手机与电脑上滚动条都改为细窄圆角常显样式，鼠标悬停加深；不再是「滑动瞬间闪一下」看不出还能滚。
  • 弹窗 / 解锁页自适应：弹窗按 dvh 自适应高度，超出时内部滚动，底部按钮不会被裁；隐私锁解锁页整页可滚，矮屏或键盘弹出时按钮仍可达。
  • 宽表格横向可滑：盘点明细的「物资 / 系统数 / 实点数 / 差异」四列在窄屏改为表格区域横向滑动，不再挤压变形。
  • 安卓端：列表与滚动页滚动条常显，台账 / 盘点列表至少保留 140dp 可视高度（矮屏不再被上方按钮挤没），长表单弹出框内部可滚动。
十六、搜索结果与仓库口径（v8.07）
  • 不显示数量为 0 的仓库：物资查询、库存查询、库存预警、选物资弹窗里显示的「仓库库存分布」，只列真正有库存的仓库；数量为 0 的仓库不再出现（原来「主仓:12; 副仓:0」→ 现在「主仓:12」）。
  • 不显示空值：某物资所有仓库均为 0 时，不再显示「仓库:-」，整段仓库信息省略。
  • 顺序稳定：仓库分布按仓库名自然升序（A2 在 A10 前），不再因「有库存优先」重排而每次顺序不同。

安装说明

升级安装：已装 v4.0 及以上旧版的用户直接覆盖安装即可，原有数据不会丢失，数据库会自动升级到最新结构（新增的工具借还记录会保存在全新的台账类型里，不影响原有库存与统计）。

首次安装需授权：下载后点击 APK，若系统提示「未知来源应用」，请在弹窗中允许来自此来源的安装（不同机型路径略有差异：设置 → 安全/隐私 → 安装未知应用），授权后即可正常安装。

说明：v7.37 及更早版本内置的更新检查地址已失效，无法自动弹出提示，请用本页链接手动安装一次新版本；装好之后，后续新版本就能自动提醒、自动下载安装了。

稳妥做法：安装前可先在 App 内「数据管理 → 备份数据库」，备份文件保存在 内部存储/Download/大明智仓管家/。
